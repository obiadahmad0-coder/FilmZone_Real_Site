# FilmZone Real

سایت واقعی محلی با Node.js + Express + SQLite + پنل مدیر.

## اجرا
1. Node.js نصب باشد.
2. در همین پوشه اجرا کنید:
   npm install
   npm start
3. مرورگر: http://localhost:3000
4. پنل: http://localhost:3000/admin
5. نام مدیر: admin
6. رمز اولیه: ChangeMe123!  (حتماً قبل از انتشار با متغیر محیطی ADMIN_PASSWORD عوض شود.)

## قابلیت‌ها
- دیتابیس SQLite
- ورود مدیر و نشست امن
- افزودن فیلم/سریال
- آپلود پوستر و ویدیو
- پخش ویدیو در مرورگر
- دانلود فایل ویدیو
- جستجو و فیلتر
- حذف محتوا
- طراحی واکنش‌گرا

برای انتشار عمومی، HTTPS، رمز قوی، محدودیت حجم، ذخیره‌سازی ابری/CDN، بکاپ دیتابیس و سیستم مدیریت کاربران باید روی سرور تنظیم شود.
